# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of Epicrypt.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities privately to:

- infocyph@gmail.com

Please include:

- A clear description of the issue and impact.
- Affected version(s) and environment details.
- Steps to reproduce (proof of concept if possible).
- Suggested mitigation, if known.

## Response Process

We will:

1. Acknowledge receipt as quickly as possible.
2. Validate and triage the report.
3. Work on a fix and coordinate disclosure timing.
4. Publish a fix and advisory when ready.

## Disclosure Policy

Please allow time for investigation and remediation before public disclosure. Coordinated disclosure helps protect users and downstream projects.
